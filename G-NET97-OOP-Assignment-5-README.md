# G-NET97 OOP — Assignment 5: Shipping System with Extensions

C# console application extending the shipping-centers/shipments domain model with extension methods and utilities.

## Project Structure

- **Models/Shipments** — Shipment entity classes
- **Models/Centers** — Shipping center classes
- **Models/Relationships** — Relationships between entities
- **Models/Helpers** — Helper utilities
- **Models/Extensions** — Extension methods
- **Models/Utilities** — Utility classes

## How to Run

```bash
dotnet run
```

## Tech Stack

- C# / .NET
- Console Application
